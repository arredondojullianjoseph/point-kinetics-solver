# Point Reactor Kinetics Solver

**Status: Work in Progress 🚧**

Welcome! I'm currently building this point reactor kinetics solver from the ground up. This repository is just getting started, but this initial commit lays out the project structure and my overall goals.

## What's Next?
I'll be pushing updates to this repository as I build out the following components:
* **Core Solver:** Writing the numerical methods in Python (leveraging `numpy` and `scipy`) to evaluate the kinetics equations.
* **Plotting & Visualization:** Adding graphing tools using `matplotlib` to visualize reactor power and delayed neutron precursor concentrations.
* **Analytical Verification:** Benchmarking the numerical results against established analytical models (Inhour Equation & Prompt Jump Approximation) to ensure the math checks out.
* **Documentation:** Providing clear setup instructions, usage examples, and a breakdown of the underlying mathematical background.
